Mechanisoul

A systems-driven action prototype focused on expressive movement, modular combat, and understanding mechanical consciousness in a world of living machines.

Gameplay Footage

Project Summary

Mechanisoul is an action-combat prototype centered around a mechanical being discovering its own consciousness through movement, combat, and systems interaction. The project is designed as a long-term sandbox where core systems—movement, combat feel, AI behavior, and progression—can be iterated on and reused across future titles.

Intent vs Outcome

The goal was to create a difficult, yet rewarding, combat system with a variety of upgrades and combos that create a very replayable experience. I believe we were able to stick to that goal throughout development. The combo system allowed for many different types of gameplay that added replayability, and the combat was rapidly improving towards our goals for it. Unfortunately the project was cut before it was able to be developed to completion, but the game that we had represented the goals we had for the final game well.

    public void UpgradeEmotion()
    {
    upgradeLevel++;
    LevelChange();
    }

    public void DowngradeEmotion()
    {
    upgradeLevel = Mathf.Max(0, upgradeLevel - 1);
    LevelChange();
    if (upgradeLevel == 0) DeselectEmotion();
    }
